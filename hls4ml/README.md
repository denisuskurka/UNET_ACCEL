# How to run

> Run create or start script to enter Conda env.

> Then install dev version of HLS4ML!

`pip install git+https://github.com/fastmachinelearning/hls4ml@main`

> also if you want to use GPU download cuda tensorflow build

`python3 -m pip install 'tensorflow[and-cuda]'`

According to:
- https://fastmachinelearning.org/hls4ml/intro/setup.html
- https://www.tensorflow.org/install/pip
